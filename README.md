# Wazely Official Website Package

This folder is a portable brief for building the main public Wazely website. Wazely is the parent brand and Wazely CRM is the current flagship product.

## Included

- `PROMPT.md` — ready-to-paste implementation prompt.
- `CONTENT-BRIEF.md` — approved positioning, page structure, and copy direction.
- `SCREENSHOT-GUIDE.md` — where and how to use each product image.
- `assets/wazely-logo.svg` — official full Wazely logo.
- `assets/wazely-favicon.png` — official W icon.
- `assets/mona-sans.woff2` — the font used by the CRM and knowledge base.
- `screenshots/` — four branded CRM product captures.

## Important

The screenshots are brand-clean marketing references made from real CRM v3.2 documentation captures. Before the final public launch, compare them with the current live CRM and replace any capture whose UI or feature has changed. Do not publish customer names, phone numbers, credentials, or private account data in future screenshots.

No CRM, API, admin, deployment, or knowledge-base source code is changed by this package.
