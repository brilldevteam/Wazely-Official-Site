# Screenshot Usage Guide

## `crm-dashboard.png`

- Best placement: hero product frame or flagship-product overview.
- Story: one place to monitor conversations, contacts, flows, templates, and campaigns.
- Alt text: `Wazely CRM dashboard showing customer and campaign activity.`

## `crm-shared-inbox.png`

- Best placement: shared inbox feature section.
- Story: manage customer conversations, assign agents, add tags and notes, and share rich WhatsApp content such as locations.
- Alt text: `Wazely CRM shared inbox with an active customer conversation.`

## `crm-campaigns.png`

- Best placement: campaigns and analytics feature section.
- Story: create broadcasts and follow sent, delivered, read, and failed activity.
- Alt text: `Wazely CRM campaign dashboard with delivery and read analytics.`

## `crm-automation-builder.png`

- Best placement: automation feature section.
- Story: build connected workflows with triggers, messages, buttons, conditions, delays, and media.
- Alt text: `Wazely CRM visual automation builder with connected workflow steps.`

## Display rules

- Preserve each image's aspect ratio and never stretch it.
- Prefer `<picture>` or optimized image components with lazy loading below the fold.
- Use a subtle border, shadow, and browser-frame treatment instead of heavy 3D effects.
- Keep important UI readable on desktop and provide a focused crop on small screens.
- Never place private production data in replacement screenshots.
- Search all public output for `WAPI`, `Pixelstrap`, vendor URLs, credentials, and internal server instructions before launch.
